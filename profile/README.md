# MST Alert Hub Team 👋

Team project for the **MST × Hasoub Labs** Microservices & DevOps course.

**Project:** [alert-hub](https://github.com/MST-Alerthub-Team/alert-hub): microservices that alert
project managers via SMS/Email about changes in Jira, GitHub and ClickUp.

**Stack:** Java 25 · Spring Boot 4 · Kafka · PostgreSQL · MongoDB · Kubernetes (Minikube)
